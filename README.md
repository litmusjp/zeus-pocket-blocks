# Pocket Blocks

A tiny, phone-friendly falling-shapes puzzle game for short breaks. No accounts, no tracking, no build step.

## Play

- **Keyboard:** arrows move/rotate, Space drops, P pauses, N starts a new run.
- **Phone:** use the on-screen controls; swipe left/right/down and tap the board to rotate.
- **Speed:** choose 0.5× for a slower run, 1× for normal play, or 2× for a faster challenge.
- **Theme:** use the sun/moon button at the top to switch between light and dark mode. Your preference is saved locally.
- Clear rows to score. Your best score is saved locally in the browser.

## Run locally

```bash
npm start
```

Then open `http://localhost:3000`.
